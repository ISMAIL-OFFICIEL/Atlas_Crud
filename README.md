# CRUD RH Project

Application de gestion des ressources humaines en PHP.

## Installation

1. Copier `config.sample.php` en `config.php`
2. Modifier les paramètres de base de données
3. Lancer le serveur PHP ou XAMPP

## Connexion
- Email admin : `admin@yahoo.ma`
- Mot de passe : `Admin@1234` (ou `admin@1` si tu as appliqué ce nouveau hash)

## Structure
- `login.php` : connexion
- `users.php` : gestion des utilisateurs
- `employees.php` : gestion des employés
- `db.php` : connexion PDO
- `auth.php` : authentification
